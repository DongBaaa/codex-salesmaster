## 레이아웃 확인

- 780 논리 픽셀 최소 폭에서 `속성`, `프린터 관리`, `새로고침`, `진단 복사`, `1쪽 테스트`가 모두 한 줄 안에 표시됨.
- 프린터명이 긴 경우 콤보 상자에서 말줄임되지만, 바로 아래 `종류` 행에 전체 프린터명과 공유명이 표시됨.
- 본문 높이가 부족하면 본문만 세로 스크롤되고 `PDF 저장`, `파일 저장(XPS)`, `인쇄`, `취소` 푸터는 항상 고정됨.
- 1280 폭에서 프린터 선택, 상태, 페이지, 매수 영역이 잘림 없이 표시됨.
- 390/768 브라우저 폭은 WPF 데스크톱 창에 적용되지 않으며, 제품 최소 폭인 780과 확장 폭 1280으로 대체 검증함.

## 상호작용 확인

- 페이지 범위 라디오를 한 번 클릭하면 입력칸이 즉시 활성화됨.
- 활성화된 입력칸에 `1-2` 입력이 정상 반영됨.
- `진단 복사`는 Windows 클립보드 잠금 시 5회 재시도한 뒤 사용자에게 구체 오류를 표시하고 창을 유지함.
- 자동화 호스트가 클립보드를 점유한 환경에서는 성공 복사를 강제할 수 없었으나, 재시도·오류 상태·복구 흐름은 확인함.
- `1쪽 테스트`는 실제 종이를 소모하므로 자동 클릭하지 않았고, 주입식 출력기 회귀테스트로 1쪽·1부·한 부씩 출력 설정을 검증함.

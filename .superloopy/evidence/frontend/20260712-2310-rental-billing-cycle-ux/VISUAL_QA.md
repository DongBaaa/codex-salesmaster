# 렌탈 청구주기 UX Visual QA

## 검증 환경

- 대상: 거래플랜 WPF 데스크톱 렌탈 청구관리
- 빌드 기준: `1.1.677`
- 데이터: 운영 데이터와 분리된 테스트 AppData 및 로컬 테스트 API
- 실제 캡처 크기: `1669x955`, `1789x855`
- 캡처 방식: Windows Graphics Capture와 접근성 트리 동시 확인
- WPF 고정 업무창이므로 웹용 390px, 768px 모바일 뷰포트는 적용 대상이 아닙니다. Windows 화면 맞춤 상태 두 가지에서 표와 상세 패널을 확인했습니다.

## 확인한 업무 흐름

1. 렌탈 청구관리에서 거래처 요약행을 조회했습니다.
2. `2개월 2건` 실제 주기 건수 요약을 확인했습니다.
3. 요약행의 `▶`를 한 번 눌러 바로 아래에 두 개의 개별 프로필이 연속 표시되는지 확인했습니다.
4. 자식행에 `↳` 접두어와 각 프로필의 실제 청구기간, 예정일이 표시되는지 확인했습니다.
5. 펼친 상태에서 버튼이 `▼`, 상세 패널 버튼이 `프로필 접기`로 바뀌는지 확인했습니다.
6. 상세 상단에 `통일할 주기(개월)`, `선택 주기 통일`, 영향 안내가 함께 표시되는지 확인했습니다.
7. 모든 프로필이 이미 같은 주기일 때 통일 버튼이 비활성이고 이유가 표시되는지 확인했습니다.
8. 전체 프로필 개별 보기 체크박스로 지점 범위 사용자도 표시 방식을 전환할 수 있는지 확인했습니다.

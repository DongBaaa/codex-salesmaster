# 렌탈 청구주기 UX 디자인 토큰 적용 기록

- 기준 문서: `D:\거래플랜\DESIGN.md`
- 화면 성격: 데스크톱 중심의 고밀도 B2B 렌탈 청구 업무 화면
- 적용 방향: 기존 다크 네이비 테마와 표, 상세 패널, 버튼 계층을 유지하고 새 기능만 같은 컴포넌트 체계로 추가

## 적용 토큰

- 창 배경: `#151F2E`
- 최상위 카드: `#1A2B4A`
- 상세 패널: 기존 `RentalBillingWindow.xaml`의 공용 카드와 경계 스타일 재사용
- 강조 글자: `#4FC3F7`, `#5BD4FF`, `#66D9FF`
- 기본 글자: `#EAF2FF`, `#DDEBFF`
- 보조 글자: `#9FB3C8`, `#B8C7D8`
- 기본 글꼴: `Malgun Gothic`
- 입력, 버튼, 표 간격: 기존 창의 6px, 8px, 10px, 12px 간격 체계 재사용
- 동작 상태: 기존 hover, focus, disabled 스타일 재사용

## 새 UI 적용 항목

- 거래처 요약행의 펼침 버튼은 기존 표 안의 소형 작업 버튼 계층을 재사용했습니다.
- 개별 프로필 행은 `↳` 접두어로만 계층을 표시해 별도 색상이나 장식 카드를 추가하지 않았습니다.
- 주기별 건수는 `2개월 2건`, `매월 2건 · 3개월 1건`처럼 표 안에서 바로 읽히는 업무형 문구로 표시합니다.
- 주기 통일 영역은 상세 패널 상단에 배치하고 입력, 영향 안내, 실행 버튼 순서를 유지했습니다.
- 화면 전환 애니메이션은 추가하지 않았습니다.

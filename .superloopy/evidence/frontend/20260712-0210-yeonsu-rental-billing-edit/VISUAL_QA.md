# 연수구 렌탈 청구 설정 편집 — Visual QA

## 검사 환경
- 거래플랜 PC 테스트 빌드: `1.1.676`
- 테스트 API: 격리 SQLite + 로컬 API
- 계정 범위: `User / USENET_GROUP / YEONSU / OfficeOnly`
- 관찰 크기: `1669×955`, `1789×855`
- WPF 데스크톱 고정 업무창이므로 웹용 390/768/1280 반응형 검사는 적용 대상이 아니다.

## 실제 업무 흐름
1. 연수구 일반 계정으로 로그인했다.
2. 메인 창에서 렌탈 업무 → 렌탈 청구관리를 열었다.
3. 목록 19건과 `개별 청구건 직접 보기` 기본 체크를 확인했다.
4. `연수구청[문화관광과]`를 선택하고 연결 자산 1대가 해당 거래처 기준으로 재조회되는 것을 확인했다.
5. `청구 주기(개월)`을 36에서 35로 수정했다.
6. 저장 버튼을 누르고 계약 체결일 확인 안내의 확인 버튼으로 저장을 계속했다.
7. 저장 후 렌탈 청구관리 창이 닫히지 않았고 목록과 상세 입력값 모두 35로 재조회되었다.
8. 로컬 DB, 서버 DB, revision, outbox, dirty 상태를 대조했다.

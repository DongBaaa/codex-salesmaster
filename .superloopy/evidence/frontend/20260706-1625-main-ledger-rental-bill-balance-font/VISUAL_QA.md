# Visual QA - 메인 거래내역 렌탈 청구서 표기/잔액 글꼴

## 범위
- WPF 데스크톱 메인 화면 거래내역 DataGrid.
- 렌탈 청구관리에서 생성된 전표 유형 표시.
- 잔액 0원/잔액 존재 행의 글꼴 두께 구분.

## 디자인 토큰/일관성
- 기존 `DESIGN.md`의 다크 ERP 테이블 색상, DataGrid 구조, 버튼/카드 토큰을 유지했습니다.
- 새 색상, 새 그림자, 새 장식 요소를 추가하지 않았습니다.
- 유형 컬럼 폭만 `매출(청구서)`가 잘리지 않도록 기존 테이블 폭 체계 안에서 70에서 100으로 조정했습니다.

## 정적 UI 검증
- `MainWindow.xaml`의 거래내역 DataGrid에 `DataGrid.RowStyle` 추가 확인.
- 기본 `FontWeight=Normal`, `IsBalanceCleared=True`일 때 `FontWeight=Bold` 적용 확인.
- 세금계산서 컬럼의 무조건 Bold 표시를 제거하고, 정산 완료 상태에서만 굵게 적용하도록 조정 확인.
- 렌탈 청구 전표 유형은 `InvoiceListRow.VoucherTypeDisplay`에서 `매출(청구서)`로 표시 확인.

## 실행 검증
- 관련 테스트 4건 통과.
- 전체 데스크톱 테스트 845건 통과.
- Release 빌드 경고 0개, 오류 0개.

## 제한
- 이 변경은 WPF 데스크톱 앱의 기존 화면 일부 표시 보정이라 브라우저 390/768/1280 캡처는 적용 대상이 아닙니다.
- 실제 화면 실행 대신 XAML 구조 회귀 테스트와 전체 WPF 빌드/테스트로 검증했습니다.

## Anti-slop 체크
- 새 장식/컬러/레이아웃 패턴 없음.
- 기존 B2B 업무 테이블 정보 밀도 유지.
- 복사/조회 흐름 변경 없음.
- 데이터 저장/동기화/권한 로직 변경 없음.

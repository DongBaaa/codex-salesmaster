# 모바일 기존 전표 행 보존 — 2026-09-24

## 사전 점검
- 이전 v45는 모바일 전표 금액 비공개·오프라인 전송 검증의 진척이었다. 전체 Goal은 계속 진행 중이다.
- 수동 품목의 ItemId=null이 재편집 과정에서 Guid.Empty로 바뀌고, 등록 품목도 현재 품목 마스터 정보로 과거 전표 정보가 교체되는 경로를 확인했다. 서버는 행 ID와 당시 품목 정보를 함께 확인해 기존 계약 단가를 보존하므로 수량·비고 수정의 가격 근거가 달라질 수 있었다.
- 진행 가능: 모바일 전표 행 구성과 그 시험만 수정한다. 품목/자산 소유권, 업체/지점 범위, 서버 금액 계산·청구 정책은 변경하지 않는다. 원본 PC 업무 DB와 운영 서비스에는 쓰지 않는다.

## 변경
- 새 행 구성 시 빈 품목 GUID를 null로 정규화한다.
- 공통 FromEditor 경로를 실제 모바일 편집 저장에 연결했다. 같은 품목의 수량·비고 수정은 기존 행 ID·정렬 순서·품목명·규격·단위·자재번호·일련번호·설치장소·임대 시작/종료일을 보존한다.
- 다른 품목으로 교체하는 경우 새 품목 정보를 사용한다. 기존 비공개 행은 같은 품목을 다시 편집해도 가격이 공개되지 않으며 전송 가격은 null이다.
- 금액 조회 권한이 없는 사용자의 금액은 서버가 계산한다. 기존 행은 기존 계약 단가를 사용하며, 신규 행에는 현재 서버 품목 가격 정책을 적용한다.

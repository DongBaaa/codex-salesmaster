# 중복 품목과 휴지통의 비공개 금액 보존 — 2026-09-25

## 변경과 영향

- 정합성 조회의 품목 투영과 중복 비교 후보에 매입/매출 비공개 상태를 전달한다. 세션에 금액 권한이 있어도 품목 가격이 비공개이면 화면 및 공개 직렬화 결과에 숫자를 노출하지 않는다.
- 비공개 가격이 있으면 가격의 동일성을 판단하지 않고 병합을 차단한다. 로컬 비교·재검토에서 차단하며 서버 미리보기 및 변경 요청 이전에 반환한다. 알려진 실제 0원 후보는 기존 병합 조건을 그대로 따른다.
- 비교 스냅샷에 가격 공개 상태를 포함한다. 저장용 값이 모두 0이어도 알려진 0원에서 비공개로 바뀌면 이전 비교는 유효하지 않다. 비공개 원시 가격은 스냅샷 계산에서 null로 취급한다.
- 휴지통 품목의 매출 가격 표시도 품목 자체의 비공개 상태를 확인한다. 이름·수량·비고와 복원 권한은 유지한다. 복원 로직 자체는 변경하지 않았으며, 기존 로직이 비공개 상태·null 전송·원래 비고를 보존하는지 격리 DB에서 검증했다.
- 자산/품목 소유, 업체·지점, 전표/청구, 거래처 조회 범위와 일반 비금액 저장 정책은 변경하지 않는다. 서버·모바일 코드, 운영 DB와 실제 자료 병합·복원은 변경하지 않는다.

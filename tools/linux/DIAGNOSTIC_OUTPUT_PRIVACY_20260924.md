# 운영점검 상세·엑셀 금액 권한 보호 — 2026-09-24

## 문제와 수정

운영점검은 금액을 문자열로 미리 저장해, 조회 권한이 없거나 로그아웃·계정 전환이 발생해도 이전 금액이 상세 화면과 엑셀 출력에 남을 수 있었다. 실제 SQLite 진단을 이용한 최초 재현 11건 중 7건이 실패했다.

- `DiagnosticText`가 금액과 비금액 인수를 구분해 보관하고 출력 시 권한을 적용한다. 숫자를 정규식으로 지우지 않으므로 수량·날짜·ID·오류 설명은 유지한다.
- 전표는 판매/수금과 구매/발주/경비 방향별 금액 권한, 렌탈은 매출 금액 권한을 따른다. 거래내역은 기존 혼합 입출금 권한 정책을 재사용한다. 부모 전표를 찾을 수 없는 고아 금액이나 다른 전표에 연결된 금액은 방향을 확정할 수 없어 양쪽 권한을 요구한다.
- 전표 상세와 수금의 `AmountsHidden`도 적용해 관리자에게도 미공개 원금액을 노출하지 않는다. 비공개와 0원, 행 없음을 구별한다.
- 조회 시작 시점의 세션·권한 상태를 결과에 연결한다. 계정/권한 변경 시 화면 목록을 비우고 새로고침을 안내하며, 늦게 완료된 이전 조회와 이전 초기 결과를 재사용하지 않는다.
- 엑셀은 저장 직전 현재 로그인·조회 소유권을 다시 확인한다. 통합 문서 생성과 쓰기 동안 세션 변경 잠금을 유지해 이전 계정 자료를 뒤늦게 저장하지 않는다. 저장 창 대기 중 변경된 계정의 이전 자료도 저장하지 않는다.
- 비금액 데이터, 기존 계산·불일치 판단, 업체/지점 필터, 금액 저장 정책, dirty/outbox와 운영 DB는 변경하지 않는다.

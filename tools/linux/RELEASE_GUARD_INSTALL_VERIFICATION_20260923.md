## 남은 운영 제약
- 공식 Publisher가 `HEALTH_CHECK_RETRIES=900`을 고정 전달한다. 각 반복은 최대10초 HTTP 요청2개와 sleep1초가 있어 이론상 한 상태 확인 구간이 약5시간15분까지 늘어날 수 있다. 실패 뒤 원복도 같은 재시도 수를 사용한다. Docker 재생성 시간은 이 계산 밖이다. 단순히 900초 중단이라고 안내하면 잘못이다.
- 허용 대기 시간을 실시간 기준으로 제한하고 실패/원복 시간과 호출자 전달을 검증하는 작업이 남아 있다. 따라서 이 도구 준비만으로 전체 운영 반영 준비 완료라고 판정하지 않는다.
- 기존 버전의 배포 프로세스는 새 lock을 따르지 않으므로 운영자가 점검 중 새 배포를 동시에 시작하지 않아야 한다. 전원 차단·SIGKILL 자동 복구와 DB 원복은 별도 범위다.
- 신규 설치 보조 도구는 앱 패키지 내용에 영향을 주지 않는다. 새 743 EXE/MSI/ZIP 재생성이 필요한 제품 변경은 없다.

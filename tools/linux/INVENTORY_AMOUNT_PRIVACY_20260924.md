# 거래플랜 품목 편집 금액 보호 — 2026-09-24

## 범위와 사전 점검
- 금액 권한이 없는 직원도 품목·수량·비고 저장을 허용하고 전표 금액은 서버가 계산한다는 사용자 결정을 유지한다.
- 이번 대상은 데스크톱 품목/재고 관리의 기본가격·등급가격·재고자산 금액과 세션을 명시하는 로컬 품목 저장 경로다.
- 자산 조회, 품목 소유 업체/지점, 재고 이동 수량, 전표 저장·서버 계산 규칙은 유지한다. 원본 업무 DB나 운영 서비스를 변경하지 않는다.

## 변경
- 매입 권한으로 매입단가/재고자산 금액, 매출 권한으로 매출·소매·등급단가를 표시한다. 비공개 값은 nullable projection 및 `비공개` 문자열로 표시하며 0원과 구분한다.
- 품목 원본 수정 권한이 없는 경우 가격도 편집할 수 없다. 권한 회수 시 실제 저장용 snapshot을 0으로 지우지 않고 표시/입력만 차단한다. 화면의 계정·업체DB·지점·범위·역할이 바뀌면 기존 창의 가격 표시/저장을 차단한다.
- 계정과 권한이 있는 세션을 받는 품목 저장에서 권한 없는 가격은 트랜잭션 내부에서 다시 읽은 가격으로 보존한다. 신규 품목의 비공개 가격은 0으로 초기화하고, 금액 권한 없는 등급단가 변경은 적용하지 않는다. 기존 미전송 등급가격과 outbox는 보존한다.
- 저장 도중 접근 정보가 바뀌면 원복한다. 최종 commit 시 DB 다음 세션 잠금 순서를 사용하며 commit 대기 중 UI 스레드를 점유하지 않는다.
- 기존 DecimalToString 변환기에 선택적인 hiddenWhenNull 모드를 추가했다. 비공개 표시 문자열을 다시 숫자 0으로 저장하지 않는다. 기존 모드 동작은 유지한다.

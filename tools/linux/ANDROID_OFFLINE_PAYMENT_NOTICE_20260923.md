## 실패한 시험의 정리와 판정 범위

첫 시험의 자동 정리가 서버 전표를 삭제해 해당 전표를 참조하는 가상기기의 대기 자료가 남았다. 최초 실패·DB/WAL·합성 PDF를 백업한 뒤, 전용 AVD임을 확인하고 이번 시험의 결제/거래 ID 및 첨부 ID만 로컬 대기에서 제거했다. 다른 저장 소유자의 JSON은 동일하며 실제 PC DB나 운영 DB는 접근해 쓰지 않았다. 최초 정리 도구의 ‘결제 대기 없음’ 가정도 검증에서 차단됐고, 실제 배열에서 해당 결제 ID를 확인한 뒤 정리했다. **이 정리를 동기화 성공으로 계산하지 않는다.** 새 fixture로 수행한 수정 후 재시험의 성공과 명확히 구분한다.

중단/재시작은 이번에 생성한 서버 자식 프로세스만 제어하는 감사 사본에서 실행했다. 원본 E2E 재시작 함수는 소스 프로젝트를 실행하며 시험 계정 재시드 가능성이 있어 사용하지 않았다. 같은 supervisor의 메모리 내 시험 서명키와 환경을 유지했고 계정/비밀번호/권한을 변경하지 않았다. 이 차이는 runner manifest에 기록한다.

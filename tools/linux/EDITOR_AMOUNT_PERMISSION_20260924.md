# 전표 편집 화면의 현재 계정 금액 권한

## 사전 판단과 적용

서버 응답의 금액을 null 처리한 뒤에도 기존 캐시의 단가·잔액이 전표 편집 화면에 표시될 수 있었다. 사용자 정책은 금액 조회 권한 없이 품목·수량·비고 저장 허용, 금액은 서버 계산이다. 기존 캐시를 지우지 않고 표시/편집 투영에 현재 권한을 반영하는 로컬 변경을 진행 가능으로 판단했다.

SalesViewModel은 창을 연 계정·세션·업체DB·지점에 귀속된다. 세션 갱신/로그아웃/계정·지점 변경 시 AccessChanged 이벤트가 잠금 밖에서 전달되며 화면 표시를 갱신한다. 금액은 매출/매입 권한과 전표 유형을 각각 확인한다. 금액 입력창은 null 표시/비활성, 합계·잔액·품목 가격은 비공개 표시로 전환한다. 품목 가격 원본, 입력 중인 숫자 및 기존 수정 대기 자료를 권한 회수만으로 지우거나 변경하지 않는다. 상품 검색창은 원래부터 이름/규격/재고만 표시한다.

InvoiceLineEditModel의 표시/저장 투영은 현재 권한을 다시 확인한다. 권한 없이 신규 작성하거나 수량을 수정한 행은 권한이 복구돼도 이전 금액을 보내지 않고 서버 재계산이 필요한 null 상태를 유지한다. 품목·수량·비고 변경은 유지된다. 계정/업체가 달라진 기존 창은 자동저장을 거부한다. 전표에서 금액 권한 없이 수금/지급 창으로 들어가는 경로도 차단한다.

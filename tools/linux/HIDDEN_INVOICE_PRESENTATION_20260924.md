# 전표 비공개 금액의 PC 표시 및 편집 상태

## 사전점검과 범위

사용자 결정: 금액 조회 권한 없이 품목·수량·비고를 저장할 수 있고 금액은 서버가 계산한다. 이전 null 전송 계약과 PC 저장 상태 다음 단계로, 저장된 비공개 상태를 전표 목록·미리보기·판매 편집 행까지 연결한다. 판정은 로컬 수정 진행 가능. 업체/지점 접근 범위, 운영 DB 및 원본 PC DB는 변경하지 않는다.

## 변경

- 실제 목록 SQL 투영에서 전표와 활성 행의 AmountsHidden을 보존한다. 목록 행의 금액·수금·지급·잔액은 비공개일 때 null이며 정산 완료로 판정하지 않는다. 실제 0원은 0과 정상 정산 상태를 유지한다.
- 편집 행이 비공개 상태를 복제·저장·DTO 재전송까지 유지한다. 비공개 금액 편집 바인딩은 null을 반환하고 입력을 받지 않으며, 수량·비고는 수정 가능하다. 원본 캐시 객체의 숫자는 변경하지 않는다.
- 메인/거래처 전표 미리보기, 판매 전표 합계·공급가·부가세, 편집 행 단가·금액이 비공개 상태를 표시한다. 부모 전표가 비공개인 이전 기록을 불러올 때 행에도 전달한다. 판매 초안은 비공개 행으로 합계를 계산하지 않는다.
- 전체 검사에서 발견한 과거 배포 검사 1개를 현재 계약에 맞춘다. 업로드 전에 공간을 확인하고, 업로드·운영 검사 후에만 정리하는 순서와 사전 정리 금지를 검증한다. 운영 배포 스크립트는 바꾸지 않았다.
- 검사 출력의 고정 해시 목록은 기존 재생성 도구로 갱신한다. 209개 파일/65개 디렉터리/276개 항목 제한과 최종 실행기의 해시 검증을 유지한다. 이 목록은 현재 루트의 빌드에 대한 것으로, 검토 worktree를 별도 빌드하면 다시 확인해야 한다.

## 확인한 증거

외부 증거: `D:\DevCaches\tradeplan-hidden-money-ui-20260924`.

- 별도 빌드 및 표준 Release 빌드: 경고0/오류0. 앱 DLL SHA256은 모두 `9E1CD7119A5C7CAF31C22C0B5BACF0C12B0F2D4DB9EB7F742F19FEE1DAB6CA20`.
- 최종 핵심/기존 표시 검사34개 통과. 최종 전표·판매·화면 관련532개 통과(34개와 중복 포함). 최초 외부 출력 경로 실행의 실패72개는 보존했으며 저장소 탐색이 가능한 분리 출력 위치에서 다시 실행해530개 통과했다.
- 최초 공식 Run-All에서 공개 전표 행55,000원과 하단 합계0의 불일치를 실제로 발견했다. 메인/거래처 미리보기 파생 표시 속성의 변경 알림 누락을 수정하고, 실제 WPF 바인딩2개를 추가해 최종34/532개 검사에 포함했다. 수정 후 오른쪽 모니터의 공식 테스트 앱에서 공급가50,000원/부가세5,000원/합계55,000원 표시를 확인했다. 06:15:04 앱과 Run-All은 종료0, 시험 API 종료, SQLite quick_check=ok 및 sidecar0이었다. 종료 백업의 ZIP CRC도 통과했다. 독립 복원 검증은 이번 실행에서 하지 않았다.
- 실제 SQLite 메모리 DB에서 목록 투영, 전표/행 숨김 상태, 원본 숫자 보존을 확인했다. 편집 행의 수량·비고 변경 후 null 재전송과 실제0원 표시를 확인했다.
- 합성 전표로 실제 새 SalesWindow를 오른쪽 화면에 열어 합계/공급가/부가세와 행 단가/금액의 ‘비공개’, 수량3과 비고 표시를 확인하고 정상 종료했다. 업무 DB·서버에 연결하지 않는 표시 시험이며 제한 계정의 실제 저장/동기화 완료 증거는 아니다.
- 변경 전 전체 PC 검사는4822통과/17실패였다. 실패16개는 고정 검사 파일 목록과 현재 출력 사이의 불일치, 1개는 이전 정리 순서 검사에 속한다. 비교 시13개 출력 파일이 달랐으며 두 원본 소스 항목은 일치했다. 수정 후 해당 검사군 재실행과 공식 준비/Run-All/백업은 verification.json 또는 진행 기록을 확인한다. 변경 전 전체 검사를 최신 소스 전체 통과로 기록하지 않는다.

## 남은 범위

보존 점검에서 원본 PC DB와 HEAD는 그대로였지만 원본 `.git/index` 파일 해시는 이전 `8e01c7f8...`에서 달라졌다. 이전 인덱스 항목별 목록을 확보하지 못했으므로 통계 정보 갱신인지 스테이징 내용 변경인지 확정하지 않았다. 인덱스를 원복하거나 덮어쓰지 않았으며 현재 항목 목록과 staged raw diff를 외부 증거 폴더에 저장했다. 이 실행에 대해서는 원본 인덱스 보존 완료라고 주장하지 않는다.

서버 읽기 마스킹은 아직 비활성이다. 고객 잔액, 새 단가 입력, 품목 가격, 수금·렌탈 및 다른 응답 DTO, 집계·출력·첨부, 권한 변경/계정 전환/오프라인 캐시, 구형 앱 호환 경로를 함께 완료해야 한다. 현재 수정은 저장된 비공개 상태를 일부 PC 화면까지 전달하는 단계다. 기존 설치파일과 APK가 이 수정과 일치한다고 주장하지 않는다. 통합 패키지, 공식 제한 계정 업무 검증, 수락 및 운영 반영은 미완료이며 전체 Goal은 유지한다.

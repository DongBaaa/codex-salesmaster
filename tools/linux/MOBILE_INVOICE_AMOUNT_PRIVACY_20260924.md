# 모바일 전표 입력 금액 보호 — 2026-09-24

## 사전 점검 및 범위
- 이전 v44 단계는 모바일 품목 목록/편집 금액 권한 및 실제 세션 이벤트 검증의 진척이었다. 전체 거래플랜/워크플랜 Goal은 미완료로 유지한다.
- 확인한 결함: 신규 행에 금액 권한 검사가 없으며 비공개 행을 품목에서 다시 구성할 때 비공개 상태를 잃을 수 있었다. 행의 단가·합계 표시도 비공개 상태를 사용하지 않았다.
- 금액 권한 없는 직원의 품목·수량·비고 저장과 서버 금액 계산이라는 사용자 결정을 따른다. 업체/지점·품목 소유권·자산/청구 범위와 서버 계산 정책은 변경하지 않는다.
- 이번 범위는 모바일 전표 작성/재편집·표시·오프라인 대기 요청과 PDF 전달 DTO다. 서버 응답의 Item/Grade/Rental 금액 차단, 모든 모바일 출력/실기기 흐름까지 완료한 것으로 보지 않는다.

## 변경
- 전표 종류에 맞는 매출/매입 금액 권한을 확인한다. 인증/권한 없는 단가는 `비공개`·읽기 전용으로 표시하며, 수량·비고만으로 행을 추가/수정할 수 있다.
- 비공개 행 재편집과 권한 회수 후에는 단가/금액 null을 유지한다. 저장/PDF DTO를 만드는 시점에도 접근을 다시 확인하여 UI 이벤트보다 빠른 저장에서 금액이 섞이지 않도록 한다.
- 행 단가/합계 라벨은 비공개 상태 변경을 알리는 속성에 연결한다. 품목의 다른 종류 가격도 개별 매입/매출 권한을 따른다.
- 전표 작성 시 계정을 고정해 새 계정에서 이전 초안을 저장·출력하지 못하게 한다. 페이지 재진입 시 세션/화면 이벤트를 다시 연결한다.
- 이미 숨겨진 가격은 권한 재부여만으로 0원으로 공개하지 않는다. 현재 서버 정책에 따라 금액을 다시 조회해야 한다.

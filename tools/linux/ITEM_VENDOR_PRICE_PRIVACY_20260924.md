# 거래플랜 매입처별 최근 단가 조회 보호 — 2026-09-24

## 사전 점검과 범위
- 사용자 결정: 금액 조회 권한이 없는 직원도 품목·수량·비고를 저장하고 금액은 서버가 계산한다.
- 이번 수정은 데스크톱 품목 화면의 매입처별 최근 단가 조회와 전표 편집기의 매입처 단가 캐시다. 전표 저장 정책은 기존 서버 계산 경로를 유지한다.
- 기존 tenant/office/담당지점, 최신·확정·삭제 전표 조건을 보존한다. 자산 조회·품목 원본 수정 권한·수량·전표 저장·dirty·동기화 payload는 변경하지 않는다.
- 서버 DTO의 품목·렌탈 가격, 품목 편집기의 기타 가격 입력, 전체 모바일 금액 보호까지 완료된 것은 아니다. 통합 검증·설치파일 재생성·운영 반영은 별도 단계다.

## 변경
- 매입 금액 권한 또는 저장된 전표/행의 금액 공개 여부를 SQL projection에 적용한다. 알 수 없는 단가는 nullable로 반환하고 `비공개`로 표시한다.
- 알려진 금액은 기존 양수 단가 후보 규칙을 유지한다. 비공개 행은 값이 0으로 저장돼 있어도 후보에서 제거하지 않아 과거 공개 단가로 대체하지 못하게 한다. 실제 0원 전표는 기존대로 양수 단가 후보에서 제외하며, 최근 확정 매입일 조회에는 포함한다.
- 조회 도중 계정·접근 범위·금액 권한이 바뀌면 이전 결과를 폐기한다. 화면의 기존 단가 목록/전표 캐시도 제거하고 창 종료 후 늦은 조회 적용을 차단한다.
- 금액 권한이 없는 경우에도 조회 가능한 거래처명·구분·일자·단위·전표번호와 확정 매입/매출일은 유지한다.

# 거래처 재무 요약의 비공개 금액 보호

사용자가 확정한 정책은 금액 조회 권한이 없어도 전표의 품목·수량·비고를 저장하고 금액은 서버에서 계산하는 것이다. 이번 변경은 이 저장 흐름을 유지하면서 거래처 재무 요약에서 미공개 금액을 실제 0원으로 오인하는 문제를 보완한다.

## 변경과 영향

- 선수금·미수·미지급·선지급 요약을 nullable로 표현하고 매출/매입 금액 권한을 구분한다. 해당 합계에 비공개 거래나 전표·행·수금이 포함되면 금액을 알 수 없다는 상태를 유지한다. 삭제되거나 조회 범위 밖인 자료는 합계에 포함하지 않는다.
- 메인/거래내역 조회/전표 편집/수금 창의 관련 요약은 비공개와 실제 0원을 구분한다. 최근 렌탈 청구 요약에도 비공개 상태를 전파한다. 알 수 없는 선수금으로 자동 차감 금액을 제안하지 않는다.
- 권한·세션·업체/지점 범위 변경 시 요약과 캐시를 무효화하고, 이전 비동기 조회 결과를 적용하지 않는다. 단순 토큰 갱신은 정상 요약을 지우지 않는다. 무효화 전에 시작된 조회가 캐시를 다시 채우는 경합도 방지한다.
- 업무 DB 금액, dirty/revision, 자산·품목·업체·지점 권한과 전표 저장 범위는 변경하지 않는다. 수금/지급 저장 권한도 금액 조회 권한과 별개로 유지한다.

## 검증

최종 결과와 공식 테스트 실행 증거는 `D:\DevCaches\tradeplan-financial-privacy-20260924\verification.json`에 기록한다. 신규 시험은 권한 조합, 비공개 증거 전파, 삭제/타 업체 제외, 실제 0원, 캐시 경합, 권한 회수·재부여·토큰 갱신 및 창 종료 시 구독 해제를 다룬다. 기존 실제 HTTP 전표 저장·재전송·재시작 시험도 회귀 검사에 포함한다.

- 확대 회귀 776건 통과. 마지막 수금창 구독 해제 보완 후 관련 84건(신규 14건 포함), 해시·배포·출력 검사 27건 통과. 중복 실행 건수는 합산하지 않는다.
- 공식 테스트 환경의 관리자 화면을 오른쪽 모니터에서 확인했다. 선택한 시험 거래처의 선수금/미수/미지급/선지급은 0원, 최근 렌탈 청구는 55,000원/미수 0원, 수금창 선수금 잔액도 0으로 표시됐다. 이 확인은 제한 계정의 전체 네이티브 UI 검증을 대신하지 않는다.
- 수금창 닫기 버튼과 메인 창 정상 종료를 확인했다. 수금창 F12 입력은 이번 자동화에서 닫히지 않았으며 원인은 확정하지 않았다. 단축키 전달/포커스/앱 처리 경로를 후속 확인한다.

## 남은 범위

전체 금액 비공개 처리는 아직 완료되지 않았다. 수금창의 이력/입력/개별 정산 요약, 다른 화면과 품목·렌탈 DTO, 모바일, 구형 클라이언트 업데이트 및 패키지를 계속 검증해야 한다. 거래 Pull의 금액 마스킹은 이 경로들을 검증할 때까지 비활성이다. 제한 계정의 전체 네이티브 UI 업무 흐름 및 실기기 검증도 별도 남아 있다. 이번 단계는 운영 배포·commit·push를 포함하지 않는다.

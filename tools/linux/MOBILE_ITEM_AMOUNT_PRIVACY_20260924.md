# 모바일 품목 금액 권한 — 2026-09-24

## 범위와 사전 점검
- 지난 단계(v43)는 품목 편집의 PC 가격 표시/로컬 저장 보존과 공식 실행본을 검증한 진척이었다. 이번에는 같은 권한 정책의 모바일 소비 경로를 점검했다.
- 발견: 모바일 품목 목록은 판매/소매가가 0이면 권한과 관계없이 매입가를 대체 표시했다. 상세/편집 화면도 세션의 금액 권한을 확인하지 않았다.
- 서버 ItemAmountWritePolicy는 이미 금액 권한 없는 저장에서 기존 가격을 보존한다. 그러나 Item/Grade/Rental 응답은 아직 원래 금액을 담으므로 API 수준 비공개는 별도 미완료다. DTO를 먼저 null로 바꾸면 기존 PC/모바일 역직렬화·저장에 영향을 주므로 동시 호환 전환이 필요하다.
- 품목 원본의 업체/지점 소유권, 자산/렌탈 조회, 재고 이동 및 전표 서버 계산은 변경하지 않는다. 품목 메모/수량 등 업무 입력은 기존 권한/범위 검사를 따른다. 진행 가능으로 판단한 로컬 모바일 변경이다.

## 변경
- MobileItemAmountAccess: 인증과 매입/매출 권한에 따라 가격 문자열과 목록 대체 표시를 제한한다. 판매 금액만 볼 수 있는 사용자의 목록에 매입가가 대체 노출되지 않는다.
- 품목 상세/편집: 가격 비공개와 읽기 전용을 적용한다. 숨긴 가격의 입력 문자열을 0으로 해석하더라도 저장 후보에 반영하지 않으며 기존 가격과 등급 A/B/C를 보존한다. 신규 품목의 미공개 가격은 초기 0을 유지한다.
- SessionStore: 로그인/권한 갱신/로그아웃 후 세션 잠금을 해제한 다음 변경 이벤트를 전달한다. 열린 품목 목록/편집창은 현재 접근 상태로 가격 표시를 갱신한다. 페이지가 사라지면 구독을 해제한다.
- 편집창은 생성 시 계정 소유자를 고정한다. 새 로그인 후 남은 이전 창으로 저장·삭제할 수 없다. 충돌 후 최신값 로드에도 같은 가격 표시 정책을 적용한다.
- 금액 조회 권한은 원본 품목 수정 권한을 부여하지 않는다. 가격 접근이 바뀌지 않은 경우 편집 중인 값을 보존한다.

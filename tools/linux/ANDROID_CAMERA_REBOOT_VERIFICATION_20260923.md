## 첫 실패와 시험 환경 수정

첫 실행은 재부팅 뒤 ADB reverse 연결이 사라지고 앱이 준비 화면에 있는 동안 자동화가 동기화 탭을 찾으면서 실패했다. 원래 FAIL 결과를 보존했다. 자동 정리가 서버 fixture를 삭제한 뒤 기기에 남은 해당 합성 수금/거래/사진만 DB/WAL·사진 백업과 ID/해시 검증 후 제거했다. 다른 저장 소유자의 JSON은 그대로다. **이 한정 정리는 동기화 성공 증거가 아니다.**

감사 사본에 재부팅 후 `tcp:19080` 연결 복구와 실제 동기화 탭 준비 확인을 추가했다. 연결 복구 중에도 API가 꺼져 있음을 확인했다. 새 fixture로 전체 시험을 다시 수행했으며 공식 E2E 원본은 변경하지 않았다. 이 준비 화면 관찰만으로 제품의 모든 오프라인 시작 시간이나 성능 문제가 해결됐다고 주장하지 않는다.

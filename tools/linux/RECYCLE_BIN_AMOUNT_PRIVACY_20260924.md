# 휴지통 금액 표시 보호 — 2026-09-24

## 사전 점검과 범위
- 이전 v46은 모바일 기존 전표 행 보존과 공식 PC 실행본 재검증을 완료한 진척이었다. 전체 Goal은 미완료다.
- 품목/등급/렌탈 DTO의 금액 공개 범위를 추적하다가, 휴지통 목록이 품목 단가·전표 합계·수금·거래내역·렌탈 금액을 권한과 비공개 상태를 확인하지 않고 문자열로 만드는 경로를 확인했다.
- 진행 가능: PC 휴지통 목록의 표시 보호와 세션 변경 시 갱신만 수정한다. 자산/품목/거래처/업체·지점 조회 범위, 복원/삭제 정책, 실제 금액과 dirty/outbox는 변경하지 않는다.

## 구현
- 품목 매출단가, 전표 유형에 따른 매출/매입 합계, 연결 전표에 따른 수금 금액, 거래 유형·연결 전표·혼합 입출금에 따른 거래 금액을 구분한다.
- 렌탈 청구프로필 월 기준액·자산 월요금·청구로그 금액은 매출 금액 권한을 따른다.
- 비공개로 내려온 전표/수금/거래는 관리자에게도 내부 자리값을 공개하지 않는다. 렌탈/품목 DTO의 비공개 상태 도입은 별도 후속 작업이다.
- 목록 읽기 시작 시 세션/권한 상태를 고정한다. 표시 속성을 읽을 때도 현재 상태와 비교해 권한 회수·로그아웃·새 로그인 후 이전 금액을 반환하지 않는다. 다른 권한으로 재조회하기 전까지 이전 목록의 금액은 비공개로 유지한다.
- 설정 창이 열려 있을 때 세션 변경 이벤트로 표시를 갱신하고 닫힐 때 구독을 해제한다. 비금액 정보와 사용자가 쓴 비고는 보존한다.
